# Security Policy

## Reporting a Vulnerability

We take the security of Claime seriously. Because Claime compiles unsigned Solana transactions and interacts with on-chain accounts, security and determinism are paramount.

If you believe you have discovered a vulnerability:
1. **Do NOT open a public GitHub issue.**
2. Please use [GitHub Private Vulnerability Reporting](https://github.com/quillhog0/claime/security/advisories/new) on the repository.
3. Provide detailed steps to reproduce, transaction signatures (if applicable on devnet/mainnet), and an assessment of severity.

We will acknowledge receipt within 48 hours and work with you to coordinate a responsible disclosure and patch.
